# 07 — Skills

Claude Code Skills are reusable playbooks. They sit in `.claude/skills/<skill-name>/SKILL.md` in your project (or `~/.claude/skills/...` for personal use). When you invoke them, Claude loads the skill's instructions and follows them.

This module ships one skill: **UI Pattern Picker**.

## Files

- [ui-pattern-picker/SKILL.md](ui-pattern-picker/SKILL.md) — the skill itself
- [installing-skills.md](installing-skills.md) — how to copy it into your project
- [writing-your-own-skill.md](writing-your-own-skill.md) — pattern for building team skills
