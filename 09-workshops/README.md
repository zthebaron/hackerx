# 09 — Workshops

Hands-on exercises. Run them on your real product. Each workshop has a rubric so you can self-grade or grade as a team.

## Files

- [workshop-01-discovery.md](workshop-01-discovery.md) — running a UI/UX audit on a real screen
- [workshop-02-three-options.md](workshop-02-three-options.md) — getting 3 directions and picking with tradeoff analysis
- [workshop-03-implement-verify.md](workshop-03-implement-verify.md) — a full implement→verify loop with a teammate

## How to run a workshop

- Solo: budget 60-90 minutes per workshop. Don't rush.
- Team: schedule a 2-hour slot, work in pairs, present back.
- Recurring: run one workshop a week for three weeks. By the end, the team is fluent.
