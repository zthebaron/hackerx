# How to use this course

There are three paths. Pick one.

## Path 1 — "I have a screen to fix tonight" (60 min)

You're shipping a feature this week. You don't have time to read everything.

1. Read [02-master-prompts/master-prompt.md](../02-master-prompts/master-prompt.md). Copy it.
2. Open Claude Code in your repo. Paste the master prompt.
3. Open [03-ui-ux-vocabulary/full-cheat-sheet.md](../03-ui-ux-vocabulary/full-cheat-sheet.md) in a side window.
4. When Claude proposes 3 directions, use the cheat sheet to understand the patterns it names.
5. Pick one. Implement. Verify with the [QA prompt](../05-prompt-library/10-qa-verification.md).

Done. You've used 5% of the course and gotten 60% of the value.

## Path 2 — "I want to install this in my team" (one weekend)

You want this workflow to be the default for everyone in your repo.

1. Read all of [01-foundations](../01-foundations/README.md) and [02-master-prompts](../02-master-prompts/README.md).
2. Copy [templates/CLAUDE.md](../templates/CLAUDE.md) to the root of your real project.
3. Copy [07-skills/ui-pattern-picker/SKILL.md](../07-skills/ui-pattern-picker/SKILL.md) to `.claude/skills/ui-pattern-picker/` in your real project.
4. Walk your team through [08-demonstrations](../08-demonstrations/README.md). Pick one to redo on your own product as a team workshop.
5. Add the [10 prompts](../05-prompt-library/README.md) to your team's snippet manager (Raycast, Alfred, Notion).

## Path 3 — "I want to actually master this" (one week, 2 hours/day)

You want to be the person on your team who can name any UI pattern, propose 3 directions for any screen, and direct Claude Code like a staff designer.

Day-by-day:

- **Day 1.** [01-foundations](../01-foundations/README.md) + [02-master-prompts](../02-master-prompts/README.md). Run the master prompt on a real screen.
- **Day 2.** [03-ui-ux-vocabulary](../03-ui-ux-vocabulary/README.md). Read every cheat sheet. Quiz yourself: name the pattern for "I want a place to type any command."
- **Day 3.** [04-modern-ui-stack](../04-modern-ui-stack/README.md). Install shadcn/ui or Radix in a sandbox if you haven't.
- **Day 4.** [05-prompt-library](../05-prompt-library/README.md). Run all 10 prompts on your real product. Save the outputs.
- **Day 5.** [06-add-ons](../06-add-ons/README.md) + [07-skills](../07-skills/README.md). Install the skill.
- **Day 6.** [08-demonstrations](../08-demonstrations/README.md). Do one demo end-to-end on your own app.
- **Day 7.** [09-workshops](../09-workshops/README.md) + [10-philosophy](../10-philosophy/README.md) + [11-final-operating-system](../11-final-operating-system/README.md). Internalize the OS.

After day 7, you can name any pattern, propose any direction, and ship UI 100x faster than before.

## A note on order

The numbered folders are a recommended order, not a hard requirement. The vocabulary module (03) is the load-bearing one. If you're skipping anything, don't skip that.
