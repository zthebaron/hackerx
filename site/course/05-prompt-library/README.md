10. [10-qa-verification.md](10-qa-verification.md) — Run the full verification loop

## How to use them

- Pick the one that fits your situation.
- Paste it into Claude Code.
- Read the output before accepting any code.
- Pair every output with the [QA verification prompt](10-qa-verification.md) before merging.

## Saving them

Recommended: install all 10 as Raycast snippets, Alfred snippets, or in a Notion library. They're worth more than any individual feature you'll ship — they shape every future feature.
