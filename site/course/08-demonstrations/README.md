# 08 — Demonstrations

Four full walkthroughs. Each one shows the complete loop: vague idea → diagnosis → 3 options → pick one → plan → implement → verify.

These aren't theoretical. They show exactly what you'd see in a Claude Code session if you ran the master prompt.

## Files

- [demo-01-dashboard-from-scratch.md](demo-01-dashboard-from-scratch.md) — building a sales dashboard for an internal CRM
- [demo-02-redesign-existing.md](demo-02-redesign-existing.md) — redesigning a settings page that became unmanageable
- [demo-03-add-ai-assistant.md](demo-03-add-ai-assistant.md) — adding an AI assistant to an analytics product
- [demo-04-mobile-first-rebuild.md](demo-04-mobile-first-rebuild.md) — turning a desktop-only field-tech tool into a mobile-first app

## How to use these

Read one before you start your own session. Then pattern-match: which demo is closest to what you're trying to do? Use that demo's prompts as your starting point.
