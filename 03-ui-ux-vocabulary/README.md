# 03 — UI/UX Vocabulary

The load-bearing module of the course.

When you can name the pattern, you can prompt for the pattern. When you can prompt for the pattern, Claude builds the right thing the first time.

## Files

- [full-cheat-sheet.md](full-cheat-sheet.md) — every pattern, in one scrollable doc
- [navigation-patterns.md](navigation-patterns.md) — sidebars, top nav, breadcrumbs, tabs, command palettes
- [disclosure-and-menus.md](disclosure-and-menus.md) — accordion, popover, tooltip, dropdown, context menu
- [dashboard-and-data.md](dashboard-and-data.md) — KPI cards, data tables, faceted filters, drill-downs
- [productivity-patterns.md](productivity-patterns.md) — global search, bulk actions, inline edit, shortcuts
- [layout-patterns.md](layout-patterns.md) — split-pane, master-detail, kanban, wizard, dashboard shell
- [trust-and-feedback.md](trust-and-feedback.md) — toast, alert banner, confirmation, undo, status badge

## How to use this module

Don't read it cover-to-cover. Use it as a lookup.

When Claude proposes a pattern in your session and you don't fully know it, search this folder and read that one entry. After 10-20 sessions, you'll know all of it without trying.
