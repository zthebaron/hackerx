# 06 — Add-Ons

Component-level upgrades for specific surfaces. Use these when a screen has a specific weakness.

## Files

- [navigation.md](navigation.md) — when the app feels hard to move through
- [dashboard.md](dashboard.md) — when the dashboard feels static
- [forms.md](forms.md) — when users hate the input flow
- [tables.md](tables.md) — when users manage records and the table is dumb
- [ai.md](ai.md) — when the app should guide, summarize, or automate
- [collaboration.md](collaboration.md) — when teams share work

## How to use

Each file is a paste-ready prompt plus the menu of specific add-ons it pulls from. Copy the prompt. Edit one or two specifics. Run.

## When you're done

Move to [07-skills](../07-skills/README.md).
